# House-Price-Prediction
The rapid growth of the real estate market has made accurate house price prediction a challenging yet essential task. This project aims to develop a machine learning-based system that predicts house prices based on various influential factors such as location, size, number of rooms, and other property features. Using a dataset of historical housing data, the model is trained to identify hidden patterns and relationships between these factors and the final selling price. Techniques such as Linear Regression, Random Forest Regressor, and XGBoost are employed to compare performance and improve prediction accuracy. The model undergoes preprocessing steps including data cleaning, feature scaling, and handling of missing values to ensure robust results. Evaluation metrics such as R² score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE) are used to assess model performance. The outcome of this project demonstrates how machine learning can effectively assist buyers, sellers, and real estate professionals in making data-driven decisions and estimating fair property values with higher precision.

The proposed system utilizes a comprehensive dataset containing historical housing data. Data preprocessing steps such as handling missing values, feature encoding, outlier detection, and normalization are performed to enhance data quality. Several regression algorithms, including Linear Regression, Decision Tree Regressor, Random Forest Regressor, and XG Boost Regressor, are implemented and compared to identify the best-performing model. Hyperparameter tuning is applied to optimize model accuracy.
